# Log Files

This folder contains application log files.

## File Types

- **`dev-server.log`** - Development server logs
- **`production-server.log`** - Production server logs
- **`server-3001.log`** - Server logs from port 3001
- **`server.log`** - General server logs

## Notes

- Logs are automatically generated during development
- Can be safely deleted to clean up space
- Add to `.gitignore` if not needed in version control
