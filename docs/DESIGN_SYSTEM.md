# Design system (as built — v1.0)

Documentation of the existing system only; nothing here is a redesign. More background: [MOBILE_UX.md](MOBILE_UX.md),
[PWA.md](PWA.md). Screenshots: [screenshots/](screenshots/README.md).

## Two surfaces

| Surface | Where | Style |
|---|---|---|
| **App** (primary product) | `app/(app)`, `app/(flow)`, pricing cards, help, upgrade prompts | Warm cream background, deep-purple primary, coral/gold accents, rounded cards and pill buttons, scoped by the `.mbp-app` class |
| **Marketing site** | `app/(site)/page.tsx` (homepage), legal pages | Older style: shadcn/ui `Button`, Tailwind purple→pink gradients on headings and CTAs, white/soft-gradient sections |

## Typography

- **Nunito** (Google font via `next/font`, weights 400–800) exposed as `--font-sans`; Tailwind `font-sans` and
  `font-display` both map to it (`tailwind.config.ts`, `app/layout.tsx`). Headings use the heavier weights
  (`font-display font-extrabold`). Toasts (sonner) inherit Nunito.
- Inputs use ≥ 16 px text (no iOS zoom on focus).

## Colour tokens (app surface, `app/globals.css` → `html:has(.mbp-app)`)

All tokens are HSL triplets used as `hsl(var(--token))` through Tailwind (`bg-primary`, `text-muted-foreground`, …).

| Token | HSL | Use |
|---|---|---|
| `--background` | 36 45% 97% (warm cream) | page background |
| `--foreground` | 252 32% 14% (deep ink) | text |
| `--card` / `--popover` | 0 0% 100% | cards, sheets |
| `--primary` | 258 56% 45% (purple) | primary buttons, active nav, links, focus ring |
| `--primary-foreground` | 0 0% 100% | text on primary |
| `--secondary` | 258 40% 95% (lavender tint) | secondary buttons, info panels |
| `--muted` / `--muted-foreground` | 36 25% 93% / 252 10% 40% | quiet surfaces / secondary text |
| `--accent` | 12 90% 95% (coral tint) | accents |
| `--destructive` | 0 72% 51% | errors, destructive actions |
| `--border` / `--input` | 36 20% 87% / 36 18% 82% | hairlines, inputs |
| `--coral`, `--gold`, `--success` | 12 88% 64% · 40 92% 56% · 152 55% 36% | decoration, ratings, success |
| `--radius` | 1rem | base radius (`rounded-lg`); cards use `rounded-2xl`/`rounded-3xl`, buttons `rounded-full` |

Gradients: `.bg-hero` (purple → violet → coral, used for "magic" CTAs and the AI badge) and `.bg-magic` (soft radial
coral/purple wash on cream, used on full-screen flows and the public RSVP page). Plan cards on the pricing page use
per-plan accents: Starter purple, Plus blue ("Most popular"), Pro emerald.

## Components (`components/app/ui.tsx`, `fields.tsx`, `BottomSheet.tsx`)

- **Buttons** — `AppButton` / `LinkButton`, variants `primary` · `magic` (hero gradient) · `secondary` · `outline` ·
  `ghost` · `danger`; sizes `sm` 40 px · `md` 48 px · `lg` 56 px; `block` for full width; built-in `loading`.
  `IconButton` is a 44 px round icon button with a required `label`.
- **Cards** — `Card` (white, `rounded-2xl`, hairline border, soft shadow), `Section` (titled block), `PageHeader`,
  `StickyCTA` (above the bottom nav), `EmptyState`, `ErrorState` (plain language + retry), `Skeleton` (shimmer,
  respects reduced motion), `Chip` (pill toggle, `aria-pressed`/radio), `ProgressRing`, `Stars`.
- **Forms** — `TextField` and `TextArea` in `fields.tsx` (label, hint, error), correct `inputmode`/`autocomplete`; `GoogleIcon` for the sign-in button.
- **Sheets** — `BottomSheet` (vaul) for forms, AI results, filters, confirmations; a draggable non-modal sheet over
  the map.
- **Upgrade prompts** — `components/billing/UpgradePrompt.tsx`: what the feature does, which plan includes it,
  "See <Plan> — $X per party".

## Navigation

- Signed-in app: sticky header (logo + profile) and a **6-item bottom navigation — Home · Plan · Activities · Discover ·
  Guests · More** (each item ≥ 44 px wide, 64 px tall). The Guests tab shows a small lock when the active party has no
  Guests & RSVP access.
- Full-screen flows (wizard, login, venue detail, public RSVP) have no tab bar; public site has a header + footer
  (Privacy · Terms · Help · Contact).

## Iconography & brand

- Icons: **lucide-react** throughout (stroke icons), emoji used sparingly in AI/party content.
- Logo: the purple party hat with sparkles on cream. Source `docs/brand/MBP.png`; 1024 px master
  `docs/brand/MBP-1024.png`; all app icons (`public/favicon.*`, `public/icons/*`, Apple touch, maskable PWA icons) are
  generated by `scripts/brand-icons.py`. Social preview: `public/og-image.png` (1200 × 630).
- Wordmark: "Magical Birthday **Planner**" (Planner in primary purple) — `components/app/Logo.tsx`.

## Mobile-first & accessibility expectations

- Designed and tested at **375 / 390 / 393 / 430 px** (Playwright projects); desktop renders the same column centred.
- Every interactive control ≥ **44 × 44 px**; `touch-action: manipulation`; no hover-only affordances.
- No horizontal scrolling at any target width (asserted in E2E).
- Safe areas: `viewport-fit=cover`, `env(safe-area-inset-*)` utilities (`.pt-safe`, `.pb-safe`, `.app-content-pb`).
- Semantic headings, `aria-current` in navigation, labelled icon buttons, `role="status"`/`aria-live` for async
  results, reduced-motion support for skeletons and entrance animations.
