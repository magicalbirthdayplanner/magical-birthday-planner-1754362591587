# Product screenshots

42 screenshots in 11 folders.

Real screenshots of the v1.0 product, captured 2026-10-04. **Public pages** (homepage, pricing, help) were captured
from production without signing in. **In-app screens** come from the local test environment (local Supabase, mock
Google Places/Maps — hence "mock photo" venue images and the schematic map — and the deterministic mock AI provider), using
throw-away test accounts (child "Mia"/"Ava", `@example.test` emails). No real users, payments, keys or tokens appear.

Mobile screens are iPhone 13 (390 × 844, downscaled to 585 px wide); desktop screens are 1440 px wide, downscaled to 1200 px.
